# 인수인계 메모: 매크로 × 팩터 ML 실험 (KOSPI, v14 기준)

작성 시점: 2026-11-17. 브랜치 `experiments/ml-macro-gated-shap`. 이 문서는 다른 대화에서 작업을 이어가기 위한 요약이며, 결과 숫자는 아래 "결과"에 적은 경로의 파일에서 재현된다.

## 1. 확정한 실험 설정 (사전 지정, 결과를 본 뒤 바꾸지 않는다)

| 항목 | 내용 |
|---|---|
| 대상 | KOSPI 적격 보통주(금융·SPAC 제외), 월 평균 약 640종목 |
| 라벨 | 다음 달 수익률 > 0 (절대 방향) |
| 포트폴리오 | 예측 확률 상위 **200개** 동일가중, 월 1회 리밸런싱, 비용 0.2% × 비중 변화량 |
| 학습 | 결정일 2016년부터 확장 윈도우(라벨 연도 ≤ Y−2), 검증 = 직전 1년, 평가 = Y |
| 평가 | **2020~2025년 72개월** (결정일 2019-12-31 ~ 2025-11-30). 2026년 10개월은 참고용 확장 |
| 주 벤치마크 | **KOSPI200 동일가중(공식)**. 시총가중 KOSPI200은 부록용 |
| 튜닝 | Optuna TPE 15회(`--quick`), 목적함수 = 검증 구간 **월별 평균 AUC** |
| 모델 | logit, lgbm, catboost, macro_gated (XGBoost·RF는 `--small-data` 때문에 미실행) |
| 변수 | 고정 17팩터(`--factor-set base`) + 매크로 5개. 부스팅 기반 변수 선정은 하지 않음 |

학습 표본은 2016년부터이지만 입력 계산에는 2015년 재무, 2013년 가격이 쓰인다(TTM, 성장률, 12개월 모멘텀).

## 3. 결과 (2020~2025년, 72개월, 95% 신뢰구간)

신뢰구간은 순환 블록 부트스트랩(블록 3개월, 5,000회). 위치: `results/v14_to2026_top200_feature/`, `results/v14_to2026_top200_gating/`의 예측값(`predictions.parquet`)에서 2020~2025년만 잘라 계산. 폴더의 `report.md`와 `metrics.csv`는 2020~2026년 **82개월** 기준이라 값이 다르다.

| 전략 | CAGR | 샤프 | MDD | 월평균 초과수익 [95% CI] (동일가중 KOSPI200 대비) | 월별 AUC [95% CI] |
|---|---|---|---|---|---|
| macro_gated | 12.0% | 0.61 | −28.0% | +0.27% [−0.24, +0.83] | 0.545 [0.530, 0.561] |
| logit Firm+Macro | 10.8% | 0.57 | −28.5% | +0.17% [−0.38, +0.72] | 0.550 [0.533, 0.567] |
| logit Firm-only | 10.7% | 0.57 | −28.5% | +0.16% [−0.39, +0.71] | 0.550 [0.533, 0.567] |
| catboost Firm-only | 10.2% | 0.54 | −30.0% | +0.13% [−0.39, +0.63] | 0.555 [0.538, 0.572] |
| lgbm Firm-only | 9.7% | 0.52 | −30.2% | +0.09% [−0.43, +0.61] | 0.552 [0.535, 0.569] |
| catboost Firm+Macro | 8.2% | 0.46 | −34.2% | −0.02% [−0.55, +0.50] | 0.549 [0.533, 0.566] |
| lgbm Firm+Macro* | 6.6% | 0.40 | −33.2% | −0.16% [−0.68, +0.41] | 0.533 [0.516, 0.548] |
| KOSPI200 동일가중 (기준) | 9.0% | 0.53 | −31.6% | | |
| KOSPI200 시총가중 (참고) | 12.8% | 0.65 | −35.9% | | |

*72개월 중 14개월에서 점수가 퇴화(월 내 점수가 거의 동일). 해석에서 제외 권장.

가설 요약:
- **예측력**: 월별 AUC 구간 하한이 모두 0.5 초과. 약하지만 우연이 아님.
- **벤치마크 대비**: 모든 초과수익 구간이 0을 포함(월 약 ±0.55%p, 연 약 ±6.5%p). 우위도 열세도 구분 불가.
- **H1 (매크로 효과)**: Firm+Macro − Firm-only AUC 차이 logit −0.0001 [−0.0002, 0.0000], catboost −0.0060 [−0.0127, 0.0000], lgbm −0.0194 [−0.0363, −0.0070](퇴화 달 포함). macro_gated − catboost Firm-only −0.0096 [−0.0173, −0.0020]. 매크로가 AUC를 높였다는 증거 없음. logit은 구조상 0(매크로가 모든 종목 점수를 같이 이동).
- **H2 (복잡한 모델)**: logit Firm-only 대비 샤프 차이 macro_gated +0.037 [−0.052, +0.131], catboost −0.026, lgbm −0.048, 모두 0 포함.
- **2026년 10개월**: 모든 모델이 동일가중 KOSPI200에 월 약 −0.9~−1.3% 뒤짐(시총가중 KOSPI200 연환산 +60.7%의 대형주 쏠림 장세). 82개월로 합치면 벤치마크와 사실상 같음(macro_gated 10.2% / 0.52 대 동일가중 8.5% / 0.46).
- 탐지 가능한 최소 효과: 72개월로는 월 약 0.85%(연 약 10.6%). 관측된 초과수익은 이보다 작아 "효과 없음"이 아니라 "이 설계로는 판단 불가".

## 4. 이번 세션에서 고친 문제 (재발 방지용)

1. **DART 계정 ID 접두사**: 2019년 이전 공시는 `ifrs_X`, 이후는 `ifrs-full_X`. `_finstate`에서 통일. (이전에는 2019년 이전 순이익·자본·영업CF·CAPEX가 전부 결측)
2. **튜닝 목적함수**: 풀드 AUC는 매크로로 월의 방향을 맞히는 모델을 보상해 월 내 점수가 퇴화함 → 월별 평균 AUC(`--tune-metric monthly`).
3. **동점 처리**: `evaluation.rank_desc`가 시드 고정 무작위로 깸(이전에는 행 순서).
4. 빈 DART 캐시(공시 없는 종목) 병합 오류, merge_asof 시간 단위(ns/us) 불일치 수정.
5. 룩어헤드 방지: 재무는 공시일(`rcept_no` 앞 8자리) 기준 병합, 매크로는 직전 월말까지 공표된 값, 뒤채움 금지.

## 5. 재현 명령

`experiments/code/ml-factor-shap`에서 실행. 데이터는 git에 없으므로 필요 시 다시 만든다.

```bash
# 가격·지수 (marcap 클론 후)
python3 prepare_marcap.py --marcap-dir data/marcap/data --out data/real --start 2013-01-01
# 매크로 (ECOS_KEY 필요, VKOSPI는 data/krx/vkospi.csv)
python3 fetch_real_data.py macro --out data/real --start-year 2013 --end-year 2026
# 재무 (DART_KEY 필요, 하루 한도 40,000콜, 쿼터 초과 시 안전하게 멈추고 같은 명령으로 이어받음)
python3 fetch_real_data.py fundamentals --out data/real --market KOSPI --start-year 2015 --max-calls 40000 --daily-budget 39000
# 실험 (feature / gating 각각)
python3 run_experiment.py --data real --quick --small-data --market KOSPI --top-n-mcap 0 \
  --start-date 2016-01-01 --train-start 2016 --test-start 2020 --test-end 2026 \
  --macro-role feature --tune-metric monthly --top-k 200 --n-jobs 4 --out results/<이름>
# 테스트
for t in tests/test_*.py; do python3 $t; done
```

주의: 백그라운드(`nohup`)로 돌린 수집 작업은 세션이 끝나면 함께 멈춘다. 상태는 `data/real/dart_cache*/*.parquet` 개수와 로그로 확인.

## 6. 알려진 한계

- 72개월, KOSPI 단일 시장. 생존편향(상장폐지 수익률 없음). 금융주 제외(공식 KOSPI200에는 포함).
- 일부 Firm+Macro 모델의 점수 퇴화가 튜닝 난수에 따라 모델을 바꿔 가며 나타남(안정적으로 해결되지 않음).
- 2026년 3분기 재무는 공시 마감(11월 중순) 전이라 거의 미반영. 정정공시로 공시일이 늦게 찍힌 보고서가 있을 수 있음(보수적, 룩어헤드 아님).
- 모든 수익률은 가격 수익률(배당 제외). 모델은 동일가중, 시총가중 지수와는 가중 방식이 다름.
- 2015년 이전 재무는 DART 전체 재무제표 API로 구하지 못했음(상용 DB 필요: TS2000, KIS-VALUE, FnGuide 등, K-IFRS 2011 전후 회계기준 불연속 주의).
- `run_experiment.py`에 `--sentiment` 옵션과 `SENTIMENT_FACTORS` 설정이 있으나 이번 세션에서 추가한 것이 아님. v14는 센티멘탈 없이 실행.

## 7. 남은 일 (우선순위 제안)

1. 2020~2025년 신뢰구간 표를 CSV로 저장 (현재는 이 문서와 터미널 출력뿐).
2. 기준선 추가: 무작위 200개 선택(몬테카를로), 단일 팩터 상위 200개.
3. XGBoost(·RF) 추가 여부 결정. 논문 방식(기본 파라미터 + 조기 종료)과의 차이 정리.
4. K별(10/50/100/200)·하위 기간 민감도 표를 주 결과와 함께 부록으로.
5. 센티멘탈 수집 시 기간은 2016-01 이후, 공표 시점 기준 정렬, 종목별 값이어야 종목 순위에 영향.
6. 논문 재구성: 파일럿 표현 제거, 음성 결과를 발견으로 서술, 위 한계 명시.
7. 결과 폴더와 코드 변경을 git에 커밋(현재 untracked / modified). 프로젝트 규칙상 커밋은 요청이 있을 때만 수행.
